## Research

**[Edge IoT IDS Benchmark](https://github.com/mebmrauf/edge-iot-ids-benchmark)** &nbsp;<sub>CO-AUTHORED</sub><br />
How do intrusion detectors hold up when every IoT device sees a different slice of the network? We compare tree ensembles, neural networks and spiking networks across four IoT security datasets, with 15 simulated federated clients and varying label skew. The repository includes the processed splits, trained models and results.
